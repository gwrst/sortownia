Polityka prywatności

Sortownia to prywatna aplikacja na macOS, z której korzysta wyłącznie jej autor, na własnych kontach Google.

  • Aplikacja łączy się z Gmail API, aby wyświetlać, porządkować i wysyłać pocztę właściciela konta (zakres gmail.modify) oraz odczytać jego adres e-mail i nazwę (openid, email, profile).
  • Dane z Gmaila są przechowywane wyłącznie lokalnie na komputerze właściciela. Tokeny dostępu są w pęku kluczy macOS.
  • Aplikacja nie ma serwera, nie przesyła danych z Gmaila autorowi, nie sprzedaje ich i nie używa do reklam.
  • Wyjątek: w skrzynkach, w których właściciel włączył funkcje AI, treść wybranych wiadomości jest przetwarzana przez model Claude (Anthropic) przez własne konto Claude Code właściciela, wyłącznie po to, by pokazać mu klasyfikację, podsumowania i odpowiedzi na jego pytania.
  • Właściciel może w każdej chwili cofnąć dostęp na stronie myaccount.google.com/permissions i usunąć dane lokalne, usuwając skrzynkę w aplikacji.

Korzystanie z danych otrzymanych z interfejsów API Google jest zgodne z Google API Services User Data Policy, w tym z wymogami „Limited Use”.

Privacy policy (English)

Sortownia is a private macOS app used only by its author with the author's own Google accounts. It uses the Gmail API (gmail.modify) to show, organize and send the account owner's mail, and openid, email, profile to read the account's address and name. Gmail data is stored only locally on the owner's Mac; tokens are kept in the macOS Keychain. There is no server; Gmail data is never sent to the developer, sold, or used for advertising. The only exception: in mailboxes where the owner turned on AI features, selected message content is processed by Anthropic's Claude model through the owner's own Claude Code account, solely to show the owner classifications, summaries and answers. Access can be revoked at any time at myaccount.google.com/permissions. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
